# 盲打训练（Touch Typing Trainer）

零构建、零依赖的纯静态盲打练习网站。双击 `index.html` 即可使用，也可用内置小服务器在局域网里用手机练。

**线上地址：https://no-belief.github.io/touch-typing/** （GitHub Pages，已验证 8/8 静态资源与本地字节一致）

| 10 | 是否加可选项（严格模式 / 时长选择 / 自定义文本） | **不加** | YAGNI：先用最小闭环满足验收，避免首版膨胀 |

## 2. 功能与页面结构设计

### 2.1 信息架构（3 个视图 + 1 个结算弹层）

```
顶栏（品牌 + 三个 Tab）
├─ 练习 practice
│   ├─ 左栏：12 级课程（按 基础/进阶/数字/符号/综合 分组，显示历史最佳 WPM，达标打勾）
│   └─ 右栏：实时 HUD（WPM / 准确率 / 用时 / 进度）+ 进度条
│            + 练习文本（逐字符着色）+ 隐藏输入缓冲区
│            + 重练本课 / 下一课 / 目标 WPM
│            + 指法键盘图（高亮下一个该敲的键 + 需要按的 Shift）
├─ 成绩 stats
│   ├─ 概览卡：练习次数 / 最高 WPM / 平均准确率 / 累计时长
│   ├─ 历史曲线（Canvas 手绘：左轴 WPM，右轴 准确率，可按课程筛选，最近 20 次）
│   └─ 最近记录表（时间 / 课程 / WPM / 准确率 / 用时）+ 清空历史
└─ 指法 guide
    ├─ 指法键盘图（按手指着色）
    ├─ 图例
    └─ 手指分工表（含对侧 Shift 说明）
结算弹层 result modal
    └─ 速度 / 原始速度 / 准确率 / 用时 / 正确字符 / 错误键次 / 最长连对 / 最常打错的键
       + 达标徽标 + 重练 / 下一课 / 查看成绩
```

### 2.2 数据模型

```js
// 课程
{ id, stage, name, hint, target /* 目标 WPM */, build() /* 生成练习文本 */ }

// 一次练习记录（localStorage: tt.runs.v1，最多 300 条，最新在前）
{ id, ts, courseId, courseName, target,
  wpm, rawWpm, acc, sec,
  chars, correct, wrong, keystrokes, misses, bestStreak, errByChar }
```

### 2.3 核心算法

- **判定**：`expected = text[index]`；`ok = (ch === expected)`；写入 `marks[index] = 1|0`、`typed[index] = ch`；`index += 1`；`index === text.length` 时结算。
- **净 WPM**：`(marks 中 1 的个数 / 5) / 分钟`。**准确率**：`(keystrokes - misses) / keystrokes`。
- **指法映射**：键盘行定义表 → 反查表 `字符 → { 键位 id, 是否需要 Shift }`；Shift 侧别由该字符所属手臂决定（左手键 → 右 Shift）。
- **输入采集（双通道）**：
  - 物理键盘：`document.keydown`，可打印字符 `preventDefault` 后交给引擎（`Backspace` 回退、`Esc` 重练、`Enter` 下一课）。
  - 移动端软键盘：`keydown` 常拿不到真实字符，改由隐藏 `<textarea>` 的 `input` 事件兜底；两者用 40ms 抑制窗口去重。
- **历史曲线**：Canvas 2D 手绘，双 Y 轴折线，DPR 自适应，无第三方图表库。

### 2.4 响应式与外观

- CSS 变量 + `prefers-color-scheme` 自动深色；无 JS 主题逻辑。
- 断点：`<=900px` 课程栏移到上方并横向换行；`<=620px` HUD 两列、正文 19px、键盘图 `--u` 缩小并横向滚动。
- 键盘图用 `--u` 变量统一控制键宽，功能键按单位倍数加宽。

## 6. 拼音打字练习

### 入口
练习页左侧课程列表新增 **「拼音」** 分组，共 **8 课 = 4 个词池 × 2 种模式**：

| 词池 | 打拼音（看汉字敲字母） | 打汉字（真实输入法上屏） |
|---|---|---|
| 平翘舌 | `py-pq-pinyin` | `py-pq-hanzi` |
| 前后鼻音 | `py-nq-pinyin` | `py-nq-hanzi` |
| 鼻边音 | `py-nb-pinyin` | `py-nb-hanzi` |
| 常用词 | `py-cy-pinyin` | `py-cy-hanzi` |

词池按最小对立成对编排（支持/资助、陈旧/成就、亲人/情人、牛奶/留念），每池 20 词，每次随机抽 16 词。

### 两种模式的区别

| | 打拼音 | 打汉字 |
|---|---|---|
| 屏幕显示 | 上方汉字提示行 + 下方拼音目标串 | 只有汉字目标串 |
| 你要敲的 | 拼音字母，词间按空格，如 `zhichi zizhu` | 用系统中文输入法打出汉字并选字 |
| 判定粒度 | 逐字母 | 逐汉字（IME 上屏后判定） |
| 速度单位 | WPM（5 字符 = 1 词） | **字/分**（CPM） |
| 依赖 | 无，手机也能练 | 需要系统中文输入法 |

打拼音模式下汉字提示行跟随光标高亮当前词，已完成的词变绿。

### 实现要点

- **判定内核完全复用** `engine.js`：拼音串和汉字串都只是"目标字符串"，逐字符比对逻辑不变。
- 新增 `assets/js/pinyin.js`：词池数据 + `build(poolId, mode)` 生成目标串与**词边界**（`start`/`end`），提示行高亮靠它。
- 拼音模式无声调（与主流全拼输入法一致）；词间空格作为一个真实字符参与判定。
- **汉字模式走 IME**：用 `compositionstart`/`compositionend` 标记组合状态，组合期间不判定；`compositionend` 时一次性读取已上屏汉字逐个判对错；进入该类课程会自动聚焦隐藏输入框。
- 成绩并入现有历史（独立 courseId）：曲线可按「平翘舌 · 打汉字」等单独筛选，不会把 WPM 与字/分混在一条线上；曲线 Y 轴标签已改为中性的「速度」。

### 拼音部分的测试

`node tools/selftest.mjs` 现在 **118 条断言**，新增部分包含：

- 四个词池存在，每池 ≥16 词
- 每个词条数据自洽：汉字为 CJK、拼音为纯小写字母、**汉字字数 == 拼音音节数**（按元音簇计数，能抓出漏写/多写拼音）
- 8 个拼音课程全部注册且 id 唯一
- 每次生成的目标串与词边界一致（`target.slice(start,end)` 必须等于该词的拼音或汉字）
- 拼音串只含 `[a-z ]`、汉字串不含空格
- 8 个拼音课程都能被逐字符敲对（准确率 100%、正确数 == 目标长度）
